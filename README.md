# Weather-App
Это веб-приложение для отображения погоды и местоположения на карте по заданным географическим координатам. Пользователь вводит широту и долготу, после чего приложение:

Отображает текущую погоду (температуру, скорость ветра, иконку погодных условий)

Показывает точку с этими координатами на интерактивной карте 2GIS

✨ Основные функции

✅ Валидация координат

  Проверка на заполненность обоих полей
  
  Проверка что введены числовые значения
  
  Проверка диапазонов:
  
  Широта: от -90 до 90 градусов
  
  Долгота: от -180 до 180 градусов


🌤️ Отображение погоды

Температура в градусах Цельсия (°C)

Скорость ветра в километрах в час (км/ч)

Иконка текущих погодных условий


🗺️ Интерактивная карта

Использование картографического сервиса 2GIS

Отображение маркера по введенным координатам

Автоматическое центрирование карты на точке

Поддержка обновления позиции маркера при новых запросах
